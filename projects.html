Student Focus Tracker - README

Project Documentation

About the Project

Student Focus Tracker is an AI-based monitoring application that helps identify student distractions such as mobile phone usage, drowsiness, and inattentiveness.

Project Goal

To deliver an AI-based real-time attention monitoring system that detects student distractions (sleeping, phone usage) and automatically generates downloadable PDF performance reports for educators.

Tech Stack

  • Backend: Python Flask
  • Computer Vision: OpenCV (Haar Cascade)
  • Frontend: HTML5, CSS3, Jinja2 Templates
  • Database: SQLite
  • PDF Generation: ReportLab

TIWON Platform - README

Completed / v1.0.0

About the Project

TIWON is built as an enterprise-grade workspace that centralizes daily operations, secure credential management, and team collaboration through a unified system. It is engineered with full separation of concerns, zero frontend framework lock-in, and comprehensive role-based access control.

Project Goal

The primary goal is to provide a unified, self-hosted productivity ecosystem that eliminates cross-organizational data leaks, automates compliance deadlines, and safeguards sensitive credentials.

Tech Stack

  • Backend: Python Flask, SQLAlchemy
  • Frontend: Vanilla JavaScript, Jinja2, CSS3
  • Database: MySQL
  • Services: APScheduler, Flask-Mail (SMTP)
